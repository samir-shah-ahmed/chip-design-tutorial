An FPGA is a grid of programmable logic, not a pile of gates that the vendor wires up for you. The pieces that show up in a utilization report are:

  • LUT — a small memory addressed by the inputs. Any Boolean function of those inputs is just a different truth table. A 4-LUT has 16 bits of configuration.
  • Flip-flop — usually sitting next to the LUT, clocked by a global clock network.
  • Carry / mux fabric — dedicated wires so an adder does not spend a LUT on the carry.
  • Block RAM — a hard memory. Inference wants a synchronous read, which is why the memory lesson was written that way.
  • DSP — a hard multiplier-accumulator. a * b may land here, or in LUTs, depending on the width and the synthesis options.
  • PLL / rPLL — a hard clock generator. You do not build a PLL out of LUTs.
  • Routing — the programmable wires between all of the above. Timing failure is often a routing problem, not a logic problem.

Gowin parts on the Tang Nano boards use the same idea with Gowin's names (CLU, BSRAM, DSP, rPLL). Exact counts belong to the device datasheet for the part printed on the chip, not to a guess in this lesson.
