A design that simulates and still misbehaves on the board is usually a pin, a clock, a reset polarity, or a timing path. The tools you have on a Tang Nano, without an external analyzer, are:

  • LEDs — sticky flags and one-hot state. The module in this lesson is that flag.
  • UART — print a byte when the flag sets. The Nano 9K track builds the transmitter. The Sipeed/Lushay UART article is written for exactly this kind of bring-up.
  • Gowin Analyzer — the vendor logic analyzer, inserted as an IP and read back over the debugger. It changes the design (it uses block RAM and routing), so a path can pass with the analyzer inserted and fail without it.

Before you reach for an analyzer, check the things simulation cannot see: the CST pin, the bank voltage, the active-low LED, and whether reset is released. Several Tang Nano "it doesn't blink" reports are one of those four.

Exercise: Make seen stick at 1 after a one-clock pulse on event_in. Reset is the only thing that clears it.
