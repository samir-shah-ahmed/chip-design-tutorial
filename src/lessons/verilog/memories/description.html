A memory in Verilog is an array of registers: reg [3:0] mem [0:7]; is eight words of four bits. Synthesis maps a large array with a synchronous read onto block RAM. A tiny array, or an asynchronous read (assign rdata = mem[addr]), often becomes flip-flops instead.

This RAM writes on the clock when we is high and presents the read data on the following clock (synchronous read). The read uses non-blocking assignment, so a write and a read in the same clock see the old word. The testbench writes on one edge and checks rdata on the next.
