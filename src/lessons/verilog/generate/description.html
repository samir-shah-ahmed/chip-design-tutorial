generate copies hardware at elaboration time. It is not a loop that runs during simulation. The result is N real instances, with N sets of wires, as if you had written them out by hand.

A ripple-carry adder is the textbook use: each stage is a full adder, and stage i takes the carry out of stage i-1. The carry chain is a bus one bit wider than the data, with carry[0] tied to 0.

Exercise: Build the carry chain with a generate for loop of full_adder instances. 3+1 should produce sum 4, and 15+1 should wrap to 0 with cout high.
