A finite state machine is a register that stores which step you are in, plus combinational logic that picks the next step from the current step and the inputs. This lesson is a Moore detector for the bit sequence 101: the hit output depends only on the state, and the state register updates on the clock.

  • S0 idle, S1 saw 1, S2 saw 10, S3 saw 101 and raises hit.
  • One always @(posedge clk) block holds the state. One always @(*) block computes the next state. Keep the assignments in the combinational block blocking.
  • Every state in the case needs a next state, including the ones you hope never happen (default). A missing branch becomes a latch.

Exercise: Fill in state S2. Feed the bits 1, 0, 1. The testbench should print PASS hit after 101.
