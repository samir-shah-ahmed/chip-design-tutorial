When a signal is produced by one clock and sampled by another, it is asynchronous to the receiving clock. Sampling it in one flip-flop can capture a value in between 0 and 1. That metastable voltage usually resolves, but the resolution time is unbounded, so the next flip-flop is there to give it a full cycle.

The two-flop synchronizer is the usual circuit for a single bit level. It does not move a multi-bit bus safely: each bit can resolve on a different clock, and the bus can be sampled as a value that never existed. Buses need a handshake, a FIFO, or a holding register with one synchronized ready bit.
