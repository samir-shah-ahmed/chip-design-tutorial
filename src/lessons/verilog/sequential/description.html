A flip-flop copies its input only on a clock edge and holds that value for the rest of the cycle. A counter is a flip-flop whose next value is its current value plus one.

The sensitivity list @(posedge clk) is the clock pin. rst in this lesson is synchronous: it is looked at on the clock edge, not as a second edge in the sensitivity list. Synchronous resets stay on the clock network and are the default style in the FPGA lessons later.
