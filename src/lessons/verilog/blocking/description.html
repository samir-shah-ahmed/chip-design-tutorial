Inside one always procedure, = and <= do not mean the same thing, even though both copy a value.

  • Blocking = updates the variable before the next statement in that procedure runs. Later statements in the same time step see the new value.
  • Non-blocking <= schedules the update for after every procedure has read the right-hand sides. Every register sees the values from before the clock edge.

Use = in combinational always @(*) blocks. Use <= in always @(posedge clk) blocks. Mixing them in one clocked block is how shift registers accidentally collapse into a single wire.

Exercise: The reset loads a=0, b=1. Change the swap so that one clock later the testbench prints PASS (a is 1 and b is 0). Blocking assignments cannot do that swap, because the second read sees the first write.
