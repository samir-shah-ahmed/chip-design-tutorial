A parameter is a constant chosen when the module is instantiated. It is how one adder description becomes an 8-bit adder in one design and a 4-bit adder in another, without copying the file.

add #(.WIDTH(4)) dut(.a(a), .b(b), .sum(sum));

localparam is the same idea, but it cannot be overridden from outside. Use it for constants that belong to the implementation, such as a state encoding.
