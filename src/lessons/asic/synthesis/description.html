Logic synthesis maps RTL onto the cells the PDK actually has. Yosys does this in steps you can read in the log: hierarchy, process (always blocks become muxes and flip-flops), techmap, and then ABC, which covers the Boolean network with the library.

What synthesis is allowed to change: the gates, the factoring, and which cell implements a function. What it is not allowed to change: the cycle-by-cycle behavior of registers, and the combinational function between them. A mux written as if and a mux written as ?: should come out as the same function. If they do not, one of them inferred a latch because a branch was missing.

initial values, delays, and $display are not cells. They disappear, or the tool errors. The FPGA note is the same: synth_gowin is synthesis onto a different library (LUTs and Gowin flip-flops) with the same contract.
