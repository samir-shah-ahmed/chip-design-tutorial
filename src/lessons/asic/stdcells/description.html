ASIC synthesis does not emit LUTs. It emits standard cells from a library: inverters, NAND, NOR, AOI, flip-flops, and clock buffers, each with a layout in the foundry's design rules. A PDK (process design kit) is the foundry data those cells, and the place-and-route rules, are built from.

Two open PDKs show up in current open silicon:

  • SkyWater sky130 — a 130 nm CMOS PDK released with Google, Efabless, and SkyWater. OpenLane's best-trodden path targets it. The PDK license is the SkyWater license, which is not the same document as this tutorial.
  • IHP SG13G2 — IHP's open 130 nm BiCMOS PDK, used by newer OpenLane and Tiny Tapeout shuttles.

The exercise uses a pretend nand2 cell so you can see a netlist without downloading a PDK. A real library cell also has timing arcs, input capacitance, and a LEF outline. Those are what static timing and placement consume.

Exercise: Build XOR out of NAND2 instances only. All four input pairs must match.
