You can run the ASIC flow on your own machine with open tools, and you can put a design on a real shuttle without a commercial license.

  • Yosys synthesizes the RTL.
  • OpenROAD floorplans, places, builds the clock tree, routes, and writes timing and layout artifacts.
  • OpenLane is the shell that runs Yosys, OpenROAD, and the magic/klayout checks from one configuration file. The classic target is sky130. Current OpenLane also targets IHP SG13G2.
  • Tiny Tapeout pools many small designs into one shuttle. You supply a top module with the port list Tiny Tapeout documents (dedicated inputs ui_in, dedicated outputs uo_out, bidirectional uio_*, ena, clk, rst_n). Their template repository is the contract to copy. The module in this lesson uses that port list so the simulator can exercise it. Submitting it still means following the current Tiny Tapeout template, because the port list has been stable but the surrounding files (info.yaml, the wrapper, the PDK) move with each shuttle.

This app does not bundle a PDK or OpenROAD. Those installs are large, and the SkyWater and IHP licenses are their own documents. The lesson is the RTL you would drop into that template, checked here before you spend a flow run.

Exercise: Increment uo_out while ena and rst_n are high. Four clocks should leave the output at 4.
