Placement, clock-tree synthesis, and routing are where the netlist acquires coordinates and wires.

  • Floorplan sets the core area, the rows the cells sit in, and where the IO pads or the macro pins are. A bad floorplan shows up later as a design that cannot route, not as a Verilog error.
  • Placement assigns each standard cell a site. Timing estimates at this stage use distances, not real metal.
  • CTS builds a buffer tree so that clk at every flip-flop skews only as much as the hold and setup budgets allow. The two flip-flops in this lesson are the smallest tree that still has skew: both clock pins must see the same edge.
  • Routing draws the nets on metal layers. Routing congestion is a real DRC-adjacent failure: the router runs out of tracks and the design does not finish.

OpenROAD runs these as separate stages. OpenLane sequences them and writes the artifacts (DEF, SPEF, GDS). This simulator has no coordinates. The exercise only checks that the two flip-flops form a two-cycle delay, which is the logical thing CTS and routing are required to preserve.

Exercise: Shift din through two registers. It must not appear on dout after one clock, and it must appear after two.
