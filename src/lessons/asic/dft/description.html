Design for test makes a manufactured chip observable. Stuck-at faults inside a block of combinational logic are tested by shifting a pattern into the flip-flops, clocking once in functional mode, and shifting the result out. That is a scan chain.

Each scan flip-flop is the functional flip-flop plus a mux on the data pin: se (scan enable) selects si (scan in) instead of d. The q of one cell feeds si of the next. Automatic test pattern generation (ATPG) writes the patterns. The scan mux is not free: it adds delay on the functional path, which is why scan insertion is done before timing closure, not after.

Boundary scan (IEEE 1149.1, JTAG) is a related but different chain around the pins, used to test the board. The Tang Nano debugger uses JTAG to program the FPGA. That is not the scan chain inside an ASIC you taped out.

Exercise: Mux si onto the flip-flop when se is high. The testbench shifts in a 1, then writes a functional 0.
