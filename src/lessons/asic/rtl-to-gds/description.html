An ASIC flow turns RTL into a GDSII layout a foundry can manufacture. The names of the stages, in the order OpenROAD and OpenLane run them, are:

  1. Synthesis — map RTL to a standard-cell netlist (Yosys, or a commercial tool).
  2. Floorplan — die size, rows, IO pins, and the macro blockages.
  3. Placement — put the standard cells in the rows.
  4. Clock tree synthesis (CTS) — insert buffers so the clock arrives at every flip-flop at nearly the same time.
  5. Routing — metal wires for every net.
  6. Static timing analysis — setup and hold on the routed design, with extracted parasitics.
  7. DRC and LVS — the drawn shapes obey the foundry rules, and the drawn transistors match the netlist.
  8. Signoff — the timing, power, and physical checks the foundry and the tapeout checklist require. Then GDSII leaves the building.

Nothing in the browser run below is a GDSII. The simulator checks the RTL you would check in before spending a place-and-route run. The open-tool path that actually writes a GDSII is the Open Silicon lesson.
