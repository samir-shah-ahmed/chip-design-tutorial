Sipeed's FAQ lists two different small boards:

  • Tang Nano — GW1N-1, QN48, C6/I5. Apicula: GW1N-LV1QN48C6/I5.
  • Tang Nano 1K — GW1NZ-1, QN48, C6/I5. Apicula: GW1NZ-LV1QN48C6/I5.

They are not the same device. A bitstream built for one will not load on the other. This track's 1K lessons target the GW1NZ part. A checked LED and clock pin table for the 1K was not included here, so this overview does not print IO_LOC lines. Copy them from the Sipeed Tang Nano 1K schematic or blink example before you program a pin. The open-source command shape is the 9K one with the 1K device string and openFPGALoader -b tangnano1k.

The in-browser blinky on the next lesson is the RTL only. Do not flash it until the CST matches your schematic.

Exercise: In top.sv, print Tang Nano 1K and finish. This only checks that the simulator is alive. The pins and commands are in the text.
