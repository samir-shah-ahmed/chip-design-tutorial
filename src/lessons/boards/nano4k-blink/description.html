One LED, one clock. Use the English Sipeed table: clock pin 45, LED pin 10, and remember pin 10 is a MODE pin that needs the dual-purpose checkbox. The conflicting Chinese table is discussed in the 4K overview. Reset, if you wire it, is pin 15 on that English page.

IO_LOC "clk" 45;
IO_PORT "clk" IO_TYPE=LVCMOS33 PULL_MODE=UP;
IO_LOC "led" 10;

The simulator still uses a one-bit bus and a tiny LIMIT. Width is 1.
