Sipeed's FAQ lists the Tang Nano 4K as GW1NSR-4C, package QN48P, speed C6/I5 or C7/I6. Apicula's nextpnr table lists GW1NSR-LV4CQN48PC7/I6. Match the speed grade to the chip you have.

The English Sipeed blink page table is:

  • sys_clk pin 45
  • sys_rst_n pin 15
  • led pin 10

An older Chinese copy of a 4K blink page lists the LED on pin 15 in one table, which is the same number that table gives the reset. The English page and a published CST that names the part GW1NSR-LV4CQN48PC7/I6 both use pin 10 for the LED. Prefer pin 10, and look at the 4K schematic if the LED does not move. The English page also says pin 10 is a MODE pin: enable "Use MODE as regular IO" (the page also mentions DONE in one sentence; the constraint section is the MODE checkbox).

The 4K has enough I/O for HDMI examples in Sipeed's TangNano-4K-example repository (camera and 720p demos). Copy those CSTs from that repository rather than from this page.

Use the open-source command shape from the Tang Nano 9K overview with --device GW1NSR-LV4CQN48PC7/I6 and openFPGALoader -b tangnano4k. Apicula's table does not require a family flag for this part.
