Memory is how digital systems store data. From CPU registers to hard drives, the memory hierarchy trades off speed, size, and cost.

Memory Hierarchy

SRAM vs DRAM

  • SRAM (Static RAM) — Uses 6 transistors per bit. Fast, doesn't need refresh. Used in caches.
  • DRAM (Dynamic RAM) — Uses 1 transistor + 1 capacitor per bit. Cheap, dense, needs periodic refresh. Used for main memory.

ROM Types

ROM (Read-Only Memory), PROM (Programmable), EPROM (Erasable), EEPROM (Electrically Erasable), Flash (block-erasable EEPROM).

Modeling Memory in Verilog

reg [7:0] mem [0:255];  // 256 x 8-bit memory

always @(posedge clk) begin
  if (write_en)
    mem[addr] <= data_in;
  data_out <= mem[addr];  // synchronous read
end
