CMOS is the technology behind virtually every digital chip made today — from your phone's processor to satellite computers.

MOS Transistors

CMOS Inverter

The simplest CMOS gate: a PMOS on top (pull-up) and NMOS on bottom (pull-down).

// When input A = 0:
//   PMOS ON  → output pulled to VDD (1)
//   NMOS OFF → no path to GND
// When input A = 1:
//   PMOS OFF → no path to VDD
//   NMOS ON  → output pulled to GND (0)
// Result: output = NOT(A)

CMOS NAND Gate

2 PMOS in parallel (pull-up) + 2 NMOS in series (pull-down). Output is LOW only when BOTH inputs are HIGH.

CMOS NOR Gate

2 PMOS in series + 2 NMOS in parallel. Output is HIGH only when BOTH inputs are LOW.

Why CMOS Wins

  • Zero static power — In steady state, one path is always OFF, so no current flows VDD→GND
  • Full voltage swing — Outputs reach full VDD or GND (unlike NMOS-only logic)
  • Scalability — Works from early μm down to today's 3nm process nodes
