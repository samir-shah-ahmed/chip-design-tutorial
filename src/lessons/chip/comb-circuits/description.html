Combinational circuits are the building blocks of all digital logic. Their outputs depend only on current inputs — no clock, no memory.

Multiplexer (MUX)

Selects one of N inputs based on select lines. A 2:1 mux needs 1 select bit; a 4:1 mux needs 2.

Decoder

Converts an N-bit binary input into 2^N output lines (one-hot):

// 2-to-4 decoder:  in=00 → out=0001
//                   in=01 → out=0010
//                   in=10 → out=0100
//                   in=11 → out=1000

Encoder / Priority Encoder

The reverse of a decoder — converts one-hot input to binary. Priority encoders handle multiple active inputs by selecting the highest priority.

Adder Circuits

Half Adder: Adds two 1-bit inputs, produces sum and carry.

sum   = a ^ b;    // XOR
carry = a & b;    // AND

Full Adder: Adds two bits plus a carry-in. Chain them for multi-bit addition (ripple-carry adder).
