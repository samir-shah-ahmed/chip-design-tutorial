Sequential circuits add memory to logic. Unlike combinational circuits, their outputs depend on both current inputs and stored state.

Latches vs Flip-Flops

D Flip-Flop

The most common storage element. Captures input D on the rising edge of clock:

always @(posedge clk)
  q <= d;   // non-blocking: "capture d into q on clock edge"

Registers

A register is simply N flip-flops in parallel, storing an N-bit value:

reg [7:0] data_reg;  // 8-bit register
always @(posedge clk)
  if (load) data_reg <= data_in;

Counters

Registers with feedback — the output feeds back to the input through an adder.

Shift Registers

Data shifts one position each clock cycle. Used for serial-to-parallel conversion:

always @(posedge clk)
  shift_reg <= {shift_reg[6:0], serial_in};
