Timing analysis is what separates a working chip from a paperweight. It ensures all signals arrive at the right time.

Setup and Hold Time

Propagation Delay

Every gate takes time to produce its output. The critical path is the longest combinational delay between two flip-flops — it determines maximum clock frequency:

T_clk > T_cq + T_logic + T_setup
// T_cq:    clock-to-q delay of source flip-flop
// T_logic: combinational logic delay (critical path)
// T_setup: setup time of destination flip-flop

Maximum frequency = 1 / T_clk

Clock Skew

Clock doesn't arrive at all flip-flops simultaneously. The difference is skew. Positive skew helps setup but hurts hold; negative skew does the opposite.

Metastability

When setup or hold time is violated, the flip-flop enters an unpredictable state. It eventually settles to 0 or 1, but the settling time is random. Synchronizers (two flip-flops in series) reduce metastability probability.
