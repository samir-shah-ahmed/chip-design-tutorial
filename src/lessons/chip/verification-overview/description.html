Verification is the most critical and time-consuming phase of chip design. An undetected bug that reaches silicon can cost millions to fix.

Verification Approaches

Coverage-Driven Verification

Instead of hoping your tests hit all corner cases, measure coverage — what percentage of the design space has been exercised.

  • Code Coverage — Which lines/branches were executed? (automated)
  • Functional Coverage — Which design scenarios were hit? (manually defined)
  • Toggle Coverage — Which signals changed value?

Assertions (SVA)

// SystemVerilog Assertion: req must be followed by ack within 5 cycles
property req_ack;
  @(posedge clk) req |-> ##[1:5] ack;
endproperty
assert property (req_ack) else $error("Ack timeout!");

The Verification Plan

  1. Define all features and scenarios to test
  2. Write directed tests for basic functionality
  3. Add constrained random tests for corner cases
  4. Measure coverage and add tests to close gaps
  5. Run regression: all tests pass on every code change
