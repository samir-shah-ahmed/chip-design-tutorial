The journey from an idea to a manufactured chip follows a well-defined multi-stage flow. Each stage builds on the previous one, with verification at every step.

The Chip Design Flow

Stage Details

  1. Specification — Define what the chip does, its interfaces, performance targets
  2. Architecture — Block diagram, data paths, control flow, bus architecture
  3. RTL Design — Write Verilog/SystemVerilog code describing the hardware
  4. Verification — Simulate, formal verify, and ensure correctness (60-70% of effort!)
  5. Synthesis — Convert RTL to gate-level netlist using standard cell libraries
  6. Place & Route — Physical layout: place cells, route wires, optimize timing
  7. Tapeout — Final sign-off checks, generate GDSII masks for fabrication

Key insight: Verification consumes the majority of chip design effort. A bug found at tapeout costs millions to fix. A bug found in simulation costs minutes.
