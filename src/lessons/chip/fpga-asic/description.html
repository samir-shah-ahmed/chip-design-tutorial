The FPGA Design and ASIC Design tracks go further than this overview: fabric and timing on one side, RTL-to-GDSII and open PDKs on the other. This page is the short comparison.

There are two paths to silicon: FPGAs and ASICs. Understanding both is essential for any chip designer.

FPGA Architecture

  • LUTs (Look-Up Tables) — Implement any N-input Boolean function
  • Flip-Flops — Storage elements in each CLB
  • Block RAM — Dedicated memory blocks
  • DSP Slices — Hardened multiply-accumulate units
  • Routing — Programmable interconnect between blocks

ASIC Design Flow

RTL Code → Synthesis → Gate-level Netlist → Place & Route
→ Timing Closure → Verification → Tapeout → Fabrication
