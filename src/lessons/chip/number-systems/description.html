Digital systems represent all information as binary — ones and zeros. Understanding number systems is the foundation of everything in chip design.

Base Systems

Verilog Number Notation

8'b10101010   // 8-bit binary = 170
8'hAA         // 8-bit hex = 170
8'd170        // 8-bit decimal = 170
8'o252        // 8-bit octal = 170

Format: <size>'<base><value> where base is b (binary), o (octal), d (decimal), or h (hex).

Signed vs Unsigned

By default, Verilog treats all values as unsigned. For signed arithmetic, use signed: 

reg signed [7:0] temp;  // -128 to +127
reg [7:0] utemp;        // 0 to 255

Two's Complement

Negative numbers are represented in two's complement:

// 4-bit examples:
// 0101 = +5
// 1011 = -5 (invert: 0100, add 1: 0101 → negated)
// Range for N bits: -2^(N-1) to +2^(N-1)-1
// 4-bit: -8 to +7
